# CPI 缺基期：沿用前次有效年增率契約

最後修改：2026/11/16（台灣時間）｜版本 v2.0｜指揮官本輪明確核准。

本版取代 2026/11/11「排除 m05、暫行計分、暫停正式配置」的處理。

- 適用事件：2026年10月核心 CPI 因2025年10月同比基期缺失。
- 原始10月年增率仍為缺值；計分使用同一 CPILFESL 序列前一次完整的2026年9月年增率。計算為 (338.896 / 330.418 − 1) × 100 = 2.565841%（六位小數）。
- 保留資料日2026-09-01、來源URL、兩期指數、原文雜湊、核驗時間及 carryForward 標記；畫面明示沿用月份。
- CPI 與 m13 各恢復原有效權重6.3%，通膨群總權重12.6%；其他群、CAP、公式及已核准S0/B0不改。
- 其他資料通過既有檢查後，允許正常總分、配置及有來源可追溯的每日歸檔。22項計分輸入包括1項核准沿用值，不表示當月22項都有新觀測。
- 例外僅限本事件；有效至2026-12-10 13:30 UTC，或官方新資料恢復，以先到者為準。每輪沿用仍使用26小時內的官方同序列驗證。一般資料缺漏、來源錯誤、未核准月份及其他指標維持原檢查。

## 實作鏈

原核心資料 → refresh_v703_predeploy.py 保存官方缺基期證據與同序列 → build_daily_v703_site.py 驗證雜湊並產生9月沿用列 → validate_v703_publication.py → V70-3-27.html 總分與兩處配置 → 每日發布與歸檔。

傳輸 publication.mode=FORMAL、scoringAllowed=true、calculationPolicy=CPI_PREVIOUS_VALID_YOY_OWNER_20261116、carriedIndicators=[m05]、excludedIndicators=[]；m05.status=USABLE、dataDate=2026-09-01。原始來源不回填10月同比。
