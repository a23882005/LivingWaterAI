Γ
Gamma 工程說明（放最後）
A / B / C 類：怎麼把「數值」變成「風險 0–10」
一句話先懂
我們先把每個指標變成 risk 0–10（0=安全、10=危險），再用權重平均成 avgRisk， 最後算 mSafe_raw = (10-avgRisk)*10。Gamma 的工作，就是讓「高風險訊號」更不容易被稀釋或誤判。
A 類（門檻/觸發型）
用 piecewiseGamma 鎖定 t5=5 不動點：
只要指標已經越過 t5（代表風險已經不小），就保證 risk ≥ 5，避免出現「False Calm（明明危險卻被算成安全）」。
例：VIX、HY OAS、MOVE、Real10Y、Δ13W 淨流動性、5yBE+Δ1M、Sahm、U3 失業率、NFP 3M Avg、LEI 連3月等。
B 類（連續/景氣循環型）
維持線性或輕 gamma：
這類指標本來就是「慢慢變壞/變好」，不適合硬門檻，否則會讓分數跳來跳去。
例：殖利率曲線/期限利差、PMI、核心通膨趨勢、金融條件等（依你的配置為準）。
C 類（噪音/估值/情緒型）
不鎖 t5=5，而且 降權/降振幅：
情緒與估值會亂飄，不能因一次波動就把 Macro 拉爆。做法：線性或 very-light gamma， 再做「中線收斂」：
risk' = 5 + α*(risk-5)（α<1，例 α=0.7）
這代表：它最多只能「提醒你脆弱度」，不會一拳把總分打爛。
WTI / DXY 的定位
WTI：不放 A 類、不進 CAP，留在 AND accelerator（油價×通膨AND）用來當加速器。
DXY：可做 A 類（防 False Calm），但不進 CAP（避免美元單點把 final 封頂）。
關於「線性 0 / 5 / 10」怎麼辦？
線性（0/5/10）只是第一步映射：把原始值映射成 risk 0–10 的「底稿」。
- A 類：底稿 → piecewiseGamma（鎖 t5） → riskA
- B 類：底稿 → lightGamma 或線性 → riskB
- C 類：底稿 → veryLight/線性 → 中線收斂（α）→ riskC
