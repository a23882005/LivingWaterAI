我們存取哪些資料、用於什麼目的

資料保存與安全措施

正式家庭資料庫保存於指定 Google Drive。受控主機在執行請求時可能處理暫存資料、設定與復原所需紀錄；備份依資源設定保存在私有位置。服務採用 HTTPS 傳輸與檔案存取權限限制，服務憑證放置於私有設定或受限的部署秘密設定。公開網站與公開程式庫不作為家庭資料、登入權杖或密碼的保存位置。

資料與授權設定會在提供服務所需期間保存。刪除或終止使用請求由管理者核對身分及範圍後處理；涉及其他家人共用資料時，會確認權限。復原備份不因撤銷授權而自動消失，刪除請求亦應涵蓋相關備份；若依法或為處理安全事件需保留部分紀錄，會說明範圍與原因。

資料何時會分享、誰能查看

Google 提供 Drive 儲存與授權服務；Hostinger 提供應用程式主機。這些服務會依提供儲存、傳輸或運作所需的範圍處理資料。部署流程使用 GitHub；真實家庭資料不提交至公開程式庫或公開部署紀錄。

ChatGPT 連線只有在使用者選擇連接並授權後才啟用。當使用者提出請求時，對應的身分資訊或功能結果可能傳送至 ChatGPT／OpenAI；其後續處理亦受使用者帳號設定及該服務政策約束。新增功能若涉及新的資料類型或用途，會先更新說明並取得必要授權。

管理者僅在取得你的許可、依你要求協助操作，或必要的安全處理與法律要求下接觸相關資料。其他家人僅可查看其被授權的範圍。

Google 使用者資料的使用限制

Family-Drive 使用 Google API 所取得的資料，僅為提供或改善使用者可見的本應用程式功能。資料不出售，不用於廣告投放、信用評分，亦不用於訓練一般用途的人工智慧模型。需要轉交資料時，僅限上述功能所需、使用者同意或法律及安全處理所必要的情況。

Family-Drive 對 Google API 資料的使用及傳輸遵循 Google API Services User Data Policy，包括其中的 Limited Use 要求。此說明不表示 Google 已完成本應用程式的驗證。
