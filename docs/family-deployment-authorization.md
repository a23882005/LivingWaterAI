# Family engineering delivery authorization

Effective 2026-10-20, Asia/Taipei.

The Owner authorizes Family PMs to use GitHub, GitHub Actions, Google Drive and relevant scheduled tasks for engineering delivery. Earlier Family GH=0 / No-GitHub restrictions are superseded. Routine implementation, review, merge, deployment and scheduling do not require repeated Owner confirmation.

Work PMs own implementation branches, tests and pull requests. The integration PM owns integration review, merge, applicable workflow runs, deployment verification, Drive archival and relevant task synchronization. Reuse existing pipelines and avoid duplicate schedules.

Completion evidence must identify the source commit, applicable workflow result, deployed output verification, archived deliverables and affected task configuration. Registration alone is not deployment. Engineering authorization does not waive acceptance tests or authorize trades. Do not commit customer data, credentials or private reports to public repositories.

Current technical contracts and test dependencies continue to apply. Independently frozen artifacts remain frozen until their specified release condition is met.
