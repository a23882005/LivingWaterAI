# Family 家人版｜指揮官正式架構裁決：GitHub 程式＋ChatGPT 按需執行＋Google Drive 正式資料庫

## 裁決狀態
**Owner 指揮官明確核定；即日起優先於先前 W8 自行選用 Hostinger／OAuth 常駐後端的工程假設。**
適用於 MOU、Joseph、Arthur、Lilian 四個家人 Project；本文件是正式架構與管理裁決，不是程式已完全接通的驗收憑證。

## 唯一核定的主要執行架構
1. **GitHub：存放、版控正式 Python 程式與 V70／V82／債券 V75／Mentor／報告模組。** 不存四戶私人資料庫或敏感持倉／憑證。
2. **Google Drive：保存四位家人各自的正式 SQLite 資料庫、正式報告及必要記錄。** 有使用者確實提出修改、確認交易或資金時，才透過當次授權工具執行正式資料讀寫、核對及回報；四戶資料嚴格分開。
3. **ChatGPT：使用者在各自家人 Project 主動提問時，才按需求取得正式 GitHub 程式與當事人 Google Drive 正式資料，在可用的程式執行工具環境中當次執行分析、寫回必要資料並讀回驗證、回覆結果。** 此處「ChatGPT 當虛擬主機」是「按需啟動並執行」，**不要求 24 小時背景常駐、不要求網站伺服器持續執行、也不要求定時偷偷讀資料**。
4. 家人只在自己的 ChatGPT Project 操作。原14項選單、四戶本人身分界線與四小時登入需求按 Owner 已核定體驗保持；登入的實作須適應 ChatGPT 按需會話及當下可用的可信工具，不得因方便而自行增設常駐伺服器。
5. **不直接連券商、不替客戶下單。** 投資計算和產出報告使用既有核定引擎與格式，不因修架構改變投資母規則。

## 明確禁止的擅自變更
- **禁止自行把 Hostinger 定成家人版正式 Python 執行主機。**
- **禁止自行把 HTTPS／OAuth／MCP 常駐後端定成家人版不可缺的前提。** 這些是前一輪中PM為解決問題擅自引入的方案，沒有 Owner 此次授權，不能用它們強迫變更主要架構。
- 不得再以「需要 24 小時不關機的虛擬主機」為理由新增部署、費用或工程程序。
- 不得自行搬遷四戶正式 DB、修改四戶資料口徑、重做已通過 Gate 或加開不相干工作。
- **既有 Hostinger 部署與 PR36～45 等程式／測試成果保留為歷史及可參考資產，並不代表 Owner 核准採 Hostinger 作未來正式執行核心。** 本次只修正架構裁決與工作方向；是否關閉、下線、清除既有網站端程式為獨立具體動作，不在本次「記錄架構」工作範圍內，不擅自操作。

## 此後 W8 應該直接做的事
在 **GitHub → ChatGPT 按需執行工具 → Google Drive** 的實際可用工具鏈上完成四戶14項選單的真實讀取、投資引擎計算、確認資料寫入、保存讀回與正式報告，並逐項記錄成功或真實工具阻礙；**不能僅改說法或貼上 MD 即宣稱程式已在各家人 Project 真正運行**。

如果 ChatGPT 當次缺少「取得或執行 GitHub 程式」「Google Drive 正式 DB 讀寫」的必要工具／授權，必須明確指出具體介面缺口並以既有能力處理；**不能未經指揮官裁定再擅自改回外部常駐服務。**
